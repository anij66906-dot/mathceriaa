# MATHCERIA - GitHub Pages

Web pembelajaran interaktif operasi perkalian kelas VII.

## File
- `index.html` — struktur halaman
- `style.css` — desain responsif
- `script.js` — latihan, evaluasi, skor, dan progres lokal

## Publikasikan dengan GitHub Pages
1. Buat repository GitHub baru, misalnya `mathceria`.
2. Pilih repository **Public** (GitHub Free Pages umumnya untuk repository publik).
3. Upload ketiga file tersebut ke root repository (bukan di dalam folder lain).
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch **main** dan folder **/(root)**, lalu tekan **Save**.
7. Tunggu beberapa menit. Link website akan muncul pada halaman Pages, biasanya:
   `https://USERNAME.github.io/mathceria/`

Jika nama repository adalah `USERNAME.github.io`, alamatnya biasanya:
`https://USERNAME.github.io/`

## Catatan
- Tidak perlu membeli hosting untuk penggunaan GitHub Pages standar.
- Progres disimpan pada browser/perangkat siswa menggunakan `localStorage`.
- Progres tidak terkirim ke guru dan tidak tersinkron antarperangkat.
- Materi dan soal contoh dapat disesuaikan dengan isi proposal dan hasil validasi ahli.
